使用教程

快速开始

启动后端服务后在浏览器打开 http://127.0.0.1:5000 即可使用。

cd D:\crawler
python app.py

界面布局

界面分为左右两栏：

  • 左侧：选择站点、填写参数、启动 / 暂停任务、查看下载记录
  • 右侧：实时日志面板，两个站点的日志完全独立，切换选项卡不会中断任务

Danbooru 使用

配置 API Key（推荐）

匿名访问受限，建议配置后使用：

  1. 登录 danbooru.donmai.us → 个人主页 → API Key 页面
  2. 生成 Key，填入 danbooru_crawler.py 顶部的两个变量
DANBOORU_LOGIN = "你的用户名"
DANBOORU_API_KEY = "你的API Key"

搜索词格式

示例说明
hatsune_miku搜索初音未来相关图片
shingeki_no_kyojin搜索进击的巨人相关图片
hatsune_miku solo多标签组合，空格分隔
标签名称在 Danbooru 网站搜索框中确认，单词间用下划线连接。

含已删除图片

开启开关后额外搜索已删除帖子。已删除帖子可能无原图链接，日志中会提示跳过。

文件保存结构

downloads/{搜索词}/danbooru/{作者名}/{文件名}.jpg

Yande.re 使用

搜索词格式

示例说明
hatsune_miku搜索初音未来
hatsune_miku rating:s只搜索安全级别内容

首次下载会批量查询标签类型（作者 / 角色分类），速度稍慢属正常现象。

文件保存结构

downloads/{搜索词}/yande/{作者名}/{文件名}.jpg

暂停 / 继续

任务运行时，点击开始按钮旁的 ⏸ 暂停，状态指示灯变为橙色。任务会在当前图片下载完成后暂停，不会截断文件。点击 ▶ 继续。

下载记录管理

每次下载成功后自动记录帖子 ID，下次运行自动跳过已下载内容。两个站点记录独立：

  • D.downloaded_danbooru.json
  • Y.downloaded_yande.json

点击下载记录右侧 ✕ 可重置该搜索词记录，下次将重新下载所有图片。

常见问题

问题解决方法
遇到 403 错误配置 Danbooru API Key
下载速度慢正常，程序有请求间隔以避免被封
部分图片跳过已删除帖子原图已从服务器移除
关闭页面任务停了吗不会，关闭浏览器不影响后台任务
